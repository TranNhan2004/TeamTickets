# Title

Local `@team-platform/ui` Changes Are Ignored When Angular/Vite Reuses a Stale Prebundle

# Root cause

`@team-platform/ui` is linked from a local `dist/ui` folder. Angular/Vite can reuse a previously generated dependency prebundle after the UI library is rebuilt. The browser then receives an earlier version of the component code or styles instead of the current local package.

For example, an earlier `TpTextButton` implementation did not contain the `pressEffectShape` input or the `tp-text-button--shape-*` styles. An earlier `TpAvatar` stylesheet also had a thick outer ring, while the current component uses a single thin gray border.

# Impact scope

Any changed component code or style in the local UI package can remain outdated during development. The observed symptoms were:

- A `TpTextButton` with `pressEffectShape="circle"` did not receive its circle shape class, so its button and press effect appeared elliptical.
- A `TpAvatar` displayed an old thick outer ring instead of the current thin gray border.

# Evidence

The normal development server rendered a button with only the `tp-text-button--md` class. It did not render any `tp-text-button--shape-*` class or CSS rule.

The current local UI package contains the circle implementation. In a development server started without the stale prebundle, applying `tp-text-button--shape-circle` rendered a button with these computed values:

- Width: `40px`
- Height: `40px`
- Button border radius: `50%`
- Material ripple border radius: `50%`

# How to reproduce

1. Use the local `@team-platform/ui` dependency.
2. Build or update the UI library with a changed `TpTextButton` implementation.
3. Start the frontend with the normal Angular development server while it reuses an existing dependency prebundle.
4. Render a component whose code or styles changed in the UI library.
5. Inspect the component. It can show the earlier implementation or styles.

# Fix

Exclude the local UI library from the Team Tickets development-server prebundle in `frontend/angular.json`:

```json
"prebundle": {
  "exclude": ["@team-platform/ui"]
}
```

This keeps normal dependency prebundling enabled while compiling the local UI package with the current frontend build.

# Recovery steps

After rebuilding the UI library, clear the old cache once and restart the frontend server:

```bash
cd team-tickets/frontend
npx ng cache clean
npm start
```

# Expected behavior

After a local UI-library rebuild, the frontend should load the current component code and styles. A button configured with `pressEffectShape="circle"` should render as a square button with a circular press effect, and `TpAvatar` should render with only a thin gray border.
