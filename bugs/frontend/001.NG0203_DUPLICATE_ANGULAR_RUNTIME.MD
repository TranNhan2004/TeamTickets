# Title

NG0203 Error When Showing Angular Material Components From the Local `@team-platform/ui` Library

# Root cause

`@team-platform/ui` is linked from a local folder. By default, Angular/Vite follows this link to the UI project folder. It then loads Angular and CDK from `team-platform-ui/node_modules` instead of `frontend/node_modules`.

This makes the browser load Angular twice. The UI library uses one Angular copy, while the frontend app uses the other. Because these copies do not share the same dependency injection context, Angular Material's `HighContrastModeDetector` causes the `NG0203` error.

# Impact scope

Any page that uses an Angular Material component from `@team-platform/ui` can fail to load. In this case, the home navigation bar failed while showing `TpBellNotification`, so the page content did not appear.

# How to fix

Set `preserveSymlinks` to `true` in the `frontend/angular.json` build options. Angular/Vite will then use `frontend/node_modules/@team-platform/ui`. The UI library and frontend app will use the same Angular and CDK installation.

Restart `ng serve` after this change. The fix was checked by opening the home page in Chrome, confirming that `TpBellNotification` showed without `NG0203`, and running `npm run build -- --configuration development` successfully.
